📖 Import Format Guide

JSON Format

{
  "title": "My Exam",
  "subject": "Math",
  "questions": [
    {
      "text": "Question?",
      "type": "single",
      "options": ["A", "B", "C", "D"],
      "correctAnswer": 0
    },
    {
      "text": "Earth is round?",
      "type": "truefalse",
      "correctAnswer": true,
      "passage": "Line 1 of reading text...\n\nLine 2 of reading text..."
    }
  ]
}

TXT Format: Standard MCQ

Câu 1: Question text?
A. Option 1
B. Option 2
C. Option 3
D. Option 4
Đáp án: A
Giải thích: ... (tùy chọn)

Câu 2: [Đ/S] Mệnh đề đúng sai.
Đáp án: Đ

TXT Format: Reading Passage

Đoạn văn: Reading text starts here.
You can write multiple paragraphs.

Paragraph 2 with a blank line before it.
Paragraph 3 with another blank line.

Câu 1: Question related to the passage?
A. Option 1
B. Option 2
C. Option 3
D. Option 4
Đáp án: A

Câu 2: Second question...
Đáp án: B

Hết đoạn văn (optional)
