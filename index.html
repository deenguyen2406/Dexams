📖 Import Format Guide

JSON Format

{
  "title": "My Exam",
  "subject": "Math",
  "questions": [
    {
      "text": "Question?",
      "type": "single",
      "options": ["A", "B", "C", "D"],
      "correctAnswer": 0
    },
    {
      "text": "Multi-choice?",
      "type": "multiple",
      "options": ["A", "B", "C"],
      "correctAnswers": [0, 2]
    },
    {
      "text": "Earth is round?",
      "type": "truefalse",
      "correctAnswer": true,
      "passage": "Optional reading text"
    }
  ]
}

TXT Format

Đoạn văn: Reading text... (tùy chọn)

Câu 1: Question text?
A. Option 1
B. Option 2
C. Option 3
D. Option 4
Đáp án: A
Giải thích: ... (tùy chọn)

Câu 2: Multi-choice?
A. Option 1
B. Option 2
C. Option 3
Đáp án: A,C

Hết đoạn văn (nếu muốn kết thúc đoạn văn)

Câu 3: [Đ/S] Mệnh đề đúng sai.
Đáp án: Đ
